**WaveCheck 1.0.1** for Windows 10/11 (x64) · Free for personal use

### What's new

- Fixed a crash when clicking Browse — and every file / folder / save / confirm dialog now opens without freezing the window
- Fixed the fake-24-bit detector: padded 16-in-24 'hi-res' files are now reliably caught (float rounding used to hide them)
- The verdict now always matches the final score — no more 'Studio master' next to a slashed number
- Lossy files are no longer falsely flagged 'defective' from normal encoder delay / padding
- Move never silently overwrites a file already at the destination
- Bitrate estimate now ignores embedded cover art, so a large album cover can't skew the fake-320 check
- Faster, safer library scanning — parallel with no lock contention, and symlink / junction-cycle safe
- Clipping now counts only sustained full-scale runs, not lone samples that just touch 0 dBFS
- Long or non-ASCII file paths no longer crash the results view
- Hardened DSD parsing and general robustness
