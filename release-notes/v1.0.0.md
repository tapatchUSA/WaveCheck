**WaveCheck 1.0.0** for Windows 10/11 (x64) · Free for personal use

### What's new

- Initial public release
- Fake-lossless detection via spectral cutoff vs Nyquist, with transcode + Platinum-Notes fingerprinting
- ITU-R BS.1770-4 / EBU R128 integrated loudness (LUFS) and loudness range, matched to the libebur128 reference
- 4× oversampled true-peak (inter-sample) metering
- FFT spectrum and full STFT spectrogram, click-to-zoom with pan / scroll
- Forensic metrics — bit-depth utilisation, stereo correlation, DC offset, clipping, bit-rot, audio SHA-256
- Pure-Rust DSD (.dsf / .dff) decoding — no FFmpeg dependency
- Parallel folder scan with 15-field sort, search, rubber-band multi-select, bulk move / delete, CSV / JSON export
- 7 themes + custom colour editor; built-in offline audio player
- Fully offline — no network, no telemetry; analysis is strictly read-only
